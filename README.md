# 机关谜题 · 游戏框架 + 关卡编辑器

一个「把正方形 / 圆形推到指定目标格」的机关解谜游戏**框架**，外加一个关卡编辑器。

- **双击 `index.html` 就能玩**（纯 HTML + JS，零依赖、零安装；`file://` 直接打开可用）
- 游戏内只内置了一个**机制沙盒**（把 9 种设备各摆一份，用来点着看规则和动画），**没有设计任何关卡** —— 关卡由你在编辑器里画
- 关卡按**大关分类**组织，游玩有独立的**选关界面**，带通关进度和**缩略小地图**
- **没有墙**：所有地图都是矩形，棋盘外沿就是边界
- 全部音效都是 **WebAudio 现场合成**的，不需要任何素材文件
- 能打包成**单个 HTML**（`build.cmd` → `dist\机关谜题.html`），双击即玩，也能直接发给别人

## 一、怎么玩

**游玩**页签 → 选关界面 → 点一张关卡卡片开始。操作按钮都在棋盘**正下方那一条**里。

| 操作 | 作用 |
| --- | --- |
| 点设备 | 触发一次 |
| **空格** | 撤回上一步 |
| **R** | 重开本关 |
| **B** | 返回（试玩时回编辑器，否则回选关） |
| **Enter** | 通关后进入下一关 |
| **Esc** | 返回选关界面 |
| **← →** | 上一关 / 下一关 |
| 悬停 | 预演这次点击会作用到哪些格子（绿=可行，红=冲突） |

目标：把每个**正方形**移到方形目标格，每个**圆形**移到圆形目标格，全部对上就通关（不限步数）。
通关进度会自动记住，选关卡片上有 ✓，还能一眼看到每关的缩略小地图。

**三条核心规则**

- **冲突则整体不动**：只要有一格越界 / 被占住 / 推不动，这一次点击**完全没有效果**（连「可变活塞」也不会变形）
- **设备也是操作对象**：活塞能推走设备、交换器能交换设备、旋转器能转设备、修改器能改设备
- **颜色约定**：🟢绿 = 推，🔴红 = 拉；两条箭头 = 强力，徽标「变」= 可变活塞，「反」= 换向交换器

9 种设备（详细判定见 [`docs/规则细节.md`](docs/规则细节.md)）：

1. **交换器**（12 种朝向）：交换那两格里的物品，自身不动 —— 上下 / 左右 / **四个拐角（上右·上左·下左·下右）** / 贴四条边（上斜·下斜·左斜·右斜）/ 两条对角线（主对角·副对角）
2. **旋转器**：把上下左右四格内容整体转一格（顺时针 / 逆时针）；**转过去的交换器会跟着换向**（交换轴和旋转器同方向转 90°），其它设备的朝向不变
3. **推动活塞**：把前方 1 格的物品推 1 格（只能推一个）
4. **拉动活塞**：把前方 2 格的物品拉到前方 1 格（不能推）
5. **换向交换器**：交换上下 / 左右两格，被换位置的活塞家族**朝向反转**
6. **可变活塞**：推↔拉 切换，**只有当前动作能成功时才变形**（推不动就不变）
7. **强力推动活塞**：把前方物品一直推，撞到任何东西就停在它前面
8. **强力拉动活塞**：前方任意距离最近的物品直接拉过来
9. **修改器**：沿朝向找第一个物体，若是设备就顺时针转它一格（图形会挡住）

## 二、关卡编辑器

切到顶部「✎ 关卡编辑器」。左边是**关卡信息栏**（关卡属性 + 大关/关卡树），右边只剩**笔刷 / 体检 / 快捷键**，
关卡级的操作按钮全都在棋盘**正下方那一条**上（居中，不再和右边挤）。

### 左边：关卡信息栏

- 上半部分是**当前关卡**：名字、宽 / 高 + 应用尺寸、所属大关、新建关卡、另存为副本、删除本关
- 下半部分是**大关 → 关卡树**：点大关名折叠 / 展开，点关卡名打开编辑，大关右边的 **＋** 就在这个大关里新建一关
- 最下面「大关管理」：新建大关 / 改名 / 删除（删大关会连里面的关卡一起删）/ 清空通关记录
- 新关卡名字**自动编号**（`1-3` = 第 1 大关第 3 关）
- 标题上有 **●未保存** 标记，改了没存一眼就能看见

### 中间：操作条（棋盘正下方）

`▶ 试玩(S)`｜`💾 保存并新建下一关(Ctrl+S)`｜`撤销`｜`清空物品`｜`导出 JSON`｜`导入 JSON`｜`查看 / 编辑 JSON`

### 画布操作

| 操作 | 效果 |
| --- | --- |
| 左键 / 按住拖动 | 用当前笔刷画 |
| **右键点有东西的格子 / 按住右键拖动** | 把这一格恢复成干净地板 —— **目标也一起取消**（能连擦一排） |
| **右键点空地 / `Esc`** | **放下手中的笔刷**（空手状态左键不画东西，调色板无高亮；点笔刷或按数字键重新拿起） |
| **中键**（或 Alt+左键） | 吸取该格内容作为笔刷 |
| 滚轮 | 拿着**设备**时换它的朝向 / 状态；拿着**正方形 / 圆形 / 方形目标 / 圆形目标**时，在这四种之间循环 |
| `R` 键 | 笔刷顺时针转一格（`Shift+R` 逆时针） |
| `1` `2` `3` `4` `5` `0` | 空地 / 正方形 / 圆形 / 方形目标 / 圆形目标 / 取消目标 |
| `S` | 一键试玩当前内容（不落库） |
| `B` | 试玩中一键回到编辑器，改动都还在 |
| `Ctrl+S` | 保存这一关，并**自动新建下一关（尺寸沿用当前关）** |
| `Ctrl+Z` | 撤销上一笔 |

> 尺寸最小 **1×1**、最大 60×60（墙取消之后就没理由再限制最小 3 格了）。

> `Ctrl+S` 的贴心之处：当前关卡是空的（既没图形也没目标也没设备）时**只保存、不新建**，
> 免得手快按出一串空关卡。

### 落笔动画

画东西不是「啪」地跳出来：**旧内容虚化淡出 → 新内容从小放大淡入 → 一圈柔光扩散**（覆盖同一台设备时尤其明显）。
右键擦除同理，旧内容会慢慢淡掉、带一圈红环。

### 解法录制 / 回放（确认自己画的关确实可解）

1. 按 <kbd>S</kbd> 试玩 → 通关 → 通关横幅上点「💾 记下这个解法」（那一局的点击序列就存进关卡了）
2. 按 <kbd>B</kbd> 回编辑器 → <kbd>Ctrl+S</kbd> 存进关卡
3. 右栏「解法录制」→「▶ 回放解法」：自动重放一遍，跑完会告诉你「✓ 确实可解」；中途按 Esc / B 可中断
4. 关卡后来改过、解法过期了，回放到冲突那一步会明确报「第 N 步冲突」，不会静默出错

- 解法会跟着 **Ctrl+S**、**导出 JSON**、**单文件版**一起走，所以你的关卡自带「标准答案」
- 回放**不记通关进度**（那是在验证，不是在玩）
- 「清空解法」可以把记录删掉

## 三、音效

全部用 **WebAudio 现场合成**，代码在 `js/sfx.js`，没有任何音频文件：

| 音色 | 用在哪 |
| --- | --- |
| `tick` / `click` | 选笔刷、按按钮 |
| `place` / `erase` | 画上一格 / 擦掉一格 |
| `push` / `pull` | 推动类 / 拉动类活塞（含强力、可变） |
| `rotate` / `swap` / `beam` | 旋转器 / 交换器 / 修改器 |
| `reject` | 冲突（整体不动） |
| `win` | 通关（C-E-G-C 琶音） |

顶栏 **🔊 音效** 开关，状态记在 `localStorage`。浏览器要求「用户手势之后」才能出声，
所以是第一次点击时自动解锁；没有声卡的机器上会静默降级，不会报错。

## 五、动画

不是「瞬移 + 重画」，每一下都有过渡：

- **活塞推 / 拉**：物品滑过去；强力推动带**残影拖尾**，距离越远越慢
- **旋转器**：四格物品沿**圆弧绕中心转 1/4 圈**（物品自身朝向不变 —— 旋转器只搬位置，转了再弹回来会抽搐）；
  其中的**交换器例外**：它一边绕圈一边把自己的交换轴转 90°，方向和旋转器一致（顺时针转就顺时针换向），
  位移动画和换向动画**时长对齐**，看起来就是「被整体转过去」
- **交换器**：两个物品沿外鼓弧线**互相绕过**，不穿模
- **换向交换器**：交换动画 + 活塞图标**原地翻转 180°**
- **修改器**：一道很快的**光束**打到目标设备，紧接着让它**顺时针转 90°**（整个约 0.2 秒，很快）
- **可变活塞**：动完之后图标**推↔拉闪一下**
- **冲突**：设备**抖动** + 冲突格**红闪**，右下角写明原因
- **编辑器落笔**：旧内容虚化淡出 + 新内容淡入放大 + 柔光扩散

觉得太快 / 太慢：改 `js/app.js` 里 `buildFx()` 的 `dur`，或者运行时 `MPFx.timeScale = 0.5` 整体放慢。
顶栏「动画」勾掉可以完全关闭。

## 七、做成单文件版发给别人玩

不想让对方拿到一堆 `js/` `css/`，直接打包成**一个 HTML**：

```cmd
build.cmd                                  :: 打包 + 自检（根目录有 关卡库.json 就自动带上关卡）
build.cmd 关卡库.json                       :: 指定关卡包
build.cmd samples\示例关卡包.json            :: 用自带的示例关卡包试试
```

### 做成「一份带关卡的完整游戏」

1. 编辑器 → 左栏「关卡包」→ **导出整个关卡库**（想只带一个大关就用「导出选中大关」）
2. 把导出的文件改名成 **`关卡库.json`**，放到项目根目录
3. 双击 **`build.cmd`**

打出来的 **`dist\带关卡-<包名>.html`** 就是完整游戏：对方双击打开，**第一次进来自动就有关卡**，
直接选关开玩，不需要你附带任何别的东西。

- 关卡只在他**第一次打开**（他自己浏览器里还没有任何关卡）时才会装进去，**绝不会覆盖他自己画的东西**
- 想更新关卡：重新导出一份 `关卡库.json` 再打包，发给对方即可（同一份会被识别成新包）
- 少量浏览器禁用了 `file://` 的本地存储时进度记不住，但关卡能正常玩
- 编辑器里还有个 **「导入关卡包」** 按钮：对方想把你后来的关卡补进去（或者你想把别人的关卡拿过来）就点它，
  是**副本导入**，不会覆盖现有内容

产物都在 `dist\`：

| 文件 | 说明 |
| --- | --- |
| `机关谜题.html` / `device-puzzle.html` | 不带关卡的空游戏（玩家自己画关） |
| `带关卡-<包名>.html` | **带关卡的完整游戏**，发给朋友用这个 |

因为整套代码本来就是「无模块、无 fetch、`file://` 直接可用」，所以单文件版和原版行为完全一致
（顶栏会显示 `v0.4.0 · 单文件版`，一眼能认出是哪一份）。
`tools\check-single.ps1` 会用无头 Chrome 打开单文件版自检：内联是否成功、调色板/关卡树有没有建出来，
**内嵌关卡包的话还会确认选关界面真的渲染出了关卡卡片**。

> 别人双击打开后，他的通关进度存在**他自己浏览器**里。

## 八、版本管理（git）

仓库就在本目录（`device-puzzle/`）。**每完成一次改动，都要做这三件事**：

1. 跑完三套测试，确认全绿
2. 照 `reports/_模板.md` 写一份 `reports/vX.Y.Z.md` 更新报告，并在 `CHANGELOG.md` 的版本列表里加一行
3. 一个版本一个提交，并打 tag：

```cmd
git add -A
git commit -m "feat: 一句话说清这个版本做了什么"
git tag vX.Y.Z
```

版本号：修 bug / 小调整 → 第三位 +1；新增功能 → 第二位 +1；改规则或结构 → 第一位 +1。

- 版本历史：[`CHANGELOG.md`](CHANGELOG.md)
- 更新报告：[`reports/`](reports/)（当前最新：[`reports/v0.1.0.md`](reports/v0.1.0.md)）
- 提交前请确认 `tests/dump.html` 之类的临时文件没被提交（`.gitignore` 已经挡掉了）

## 九、已知取舍

- 关卡与进度存在浏览器 `localStorage`；如果 `file://` 下浏览器禁用了存储，页面会提示，请用「导出 JSON」保存。
- 通关判定是「**所有图形都在同形状目标上**」；目标比图形多时，图形归位即通关。想改成「所有目标都必须被填满」见 `docs/规则细节.md`。
- **墙已经取消**：编辑器里没有墙笔刷、改尺寸不再铺外墙，棋盘外沿就是边界。老存档 / 老 JSON 里的 `t: 1` 仍然能读、能玩（当作静止地形），只是造不出新的了。想让我在导入时自动把墙清成地板，说一声即可。
- 几处我替你定的判定（旋转器遇阻挡整体失败、换向交换器只反转活塞家族、修改器改旋转器的含义）都写在 `docs/规则细节.md` 里并标了 ⚠️，说一声就改。
