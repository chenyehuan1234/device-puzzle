# v0.2.0 · 2026-09-19 · 两种对角线交换器 + 图形/目标滚轮 + 单文件版

## 1. 这次要解决什么

1. **再加两种交换器**：左上↔右下、左下↔右上（原来的 6 种是「上下 / 左右 / 贴着四条边」的，缺两条对角线的 X 形）
2. **图形 / 目标也能用滚轮**：在「正方形 / 圆形 / 方形目标 / 圆形目标」这四种之间滚
3. **打包成单个 HTML**：发给别人、双击就能玩，不用带一堆 js

**不做什么**：不改任何已有设备的判定，不改通关规则，不动关卡数据格式（只是 `swap` 多了两个合法状态值）。

## 4. 规则 / 交互变化

- **交换器多了两种**（`ul_dr` / `dl_ur`），都是「设备中心对称」的一对；老的 6 种判定一个字没变。
  关卡 JSON 里 `swap` 的合法 `s` 多了 `ul_dr`、`dl_ur` 两个值（老存档不受影响）。
- **滚轮语义**：以前只有设备能用滚轮；现在图形/目标这四种也能。空地 / 取消目标 / 空手时滚轮**故意不响应**
  —— 免得画着画着被滚轮换成别的笔刷。❓ 如果你希望「空地也能滚进这个循环」，说一声。
- 单文件版和原版**行为完全一致**（同一份代码，只是内联），唯一区别是顶栏多显示「· 单文件版」。

## 6. 已知问题 / 取舍

- 单文件版约 156 KB（内联了全部源码 + 注释），没有做压缩；要更小可以再加一步去注释/压缩，但会牺牲可读性。
- `dist/` 不进 git（每次 `build.cmd` 重新生成），所以换机器要先跑一次 `build.cmd`。
- 别人打开单文件版后，关卡和进度存在**他自己浏览器**里，想交换关卡要用编辑器里的「导出 / 导入 JSON」。
- 滚轮在「空地 / 取消目标 / 空手」时不动（见上，等你确认）。
