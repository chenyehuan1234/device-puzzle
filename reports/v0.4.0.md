# v0.4.0 · 2026-09-19 · 把整个大关塞进单文件版（一份带关卡的完整游戏）

## 1. 这次要解决什么

**把关卡库打包进单文件版**：给对方一个 HTML，双击打开就自动有关卡，直接选关开玩 ——
而不是「一个空游戏，玩家还得自己画关」。

拆成三件事：

1. 编辑器能**把整个关卡库（或某一个大关）导出成一个「关卡包」文件**
2. 打包时**可以带上这份关卡包**（不带也行）
3. 玩家打开带关卡的版本时**自动装进关卡库**，而且**绝不能覆盖他自己画的东西**

## 2. 改了什么

## 4. 规则 / 交互变化

- **玩法规则一个字没改**。这一版只动了「关卡怎么搬走」。
- 新增一层数据格式：**关卡包**（编辑器导出，单文件版内嵌）。旧关卡文件 / 旧存档照旧能读。
- 我的判断：
  - ❓「库里已有内容就不装内置包」—— 宁可少给，也不覆盖玩家自己的东西。想改成「每次都覆盖/合并」，改 `App.init` 里那一小段即可。
  - ❓ 导出整个库时**跳过空大关**（包干净些）；导出指定大关时即使空也保留结构。
  - ❓ 导入一律是**副本**（新 id），不做「同名覆盖」——避免误删。

## 6. 已知问题 / 取舍

- 关卡包不压缩，9 关约 13 KB；几百关会到几百 KB（单文件版本来就 180 KB 起）。
- 单文件版里的关卡**只自动装一次**：玩家删光了自己的关卡也不会重装（除非点「导入内置关卡包」）。
- 关卡包不含通关进度；对方从头玩。
- 名字里带 `\ / : * ? " < > |` 的关卡包名会被替换成 `_` 再当文件名。

## 7. 下一步建议

1. **每关最少步数**：解法长度现成的，选关卡片上显示「最少 N 步 / 你的 M 步」
2. **重做 Ctrl+Y**、**框选 / 矩形填充 / 区域复制粘贴**、**WASD 键盘光标**
3. **体检增强**：粗判有没有图形被彻底堵死
4. **提示系统**：用关卡里存的解法给玩家逐步提示
5. **打包时压缩**：单文件版去注释/压缩，能小一半
