# v0.5.0 · 2026-09-19 · 旋转器会把交换器「带着换向」（含动画方向）

## 1. 这次要解决什么

**旋转器转动时，被它转过去的交换器要跟着换向**：交换轴按旋转器的方向转 90°
（顺时针转的交换器就顺时针换向，逆时针就逆时针换向），**动画也要跟着变**。

拆成两件事：

1. 规则：旋转器转四格时，其中的 `swap`（交换器）状态跟着几何一起转
2. 表现：交换器图标在绕圈的同时**朝正确方向**转 90°，而且**和位移动画同时开始、同时结束**

## 2. 改了什么

| 需求 | 结果 | 怎么验证的 |
| --- | --- | --- |
| 1 交换器跟着换向 | 旋转器把四格整体转一格时，其中的交换器会生成一条状态变化：`s = rotateSwap(旧状态, 顺时针?)`。12 种交换器全部适用，**转四次回到自己**、**顺逆互逆** | 规则测试 16 项：`ul_ur` 顺时针 → `ur_dr`、逆时针 → `ul_dl`；`ud` 顺时针 → `lr`；一个环里两台交换器一起转；状态变化的落点是交换器的新位置、带旧状态；12 种状态转四次回到自己 |
| 1 不误伤别的设备 | 活塞家族 / 修改器 / 换向交换器的朝向**一个字都不动**（按你说的：只有交换器跟着转） | 规则测试：`states.length === 0`，活塞 `R`、修改器 `U` 原地不动；冒烟测试同样验了一遍 |
| 2 动画方向对 | 交换器的图标旋转角度从「恒定 +90°」改成**按新旧状态算出来的 ±90°**（`MP.swapDelta`），逆时针不会再倒着抽一下 | 冒烟 + 探针：顺时针 `delta = +90°`、逆时针 `delta = -90°` |
| 2 两段动画对齐 | 旋转器引起的状态过渡时长改成和位移一样（0.30s），不会出现「图标先转完、再飘过去」 | 冒烟：`st.dur === mv.dur`；探针：动画期间画面连续变化（≥4 帧不同） |
| 附带 | 规则注释 / tip / README / 规则文档同步；示例关卡包加了一关 **2-6 旋转器换向**（10 关）；版本号 0.5.0 | 示例包生成时逐关跑解法：10 关全通 |

## 4. 规则 / 交互变化

- **新增规则**（你指定的）：旋转器转过去的**交换器**，交换轴跟着旋转器方向转 90°。
  例：`ul_ur`（上斜）顺时针转 → `ur_dr`（右斜）；逆时针转 → `ul_dl`（左斜）。
- **其它设备不变**：活塞家族 / 修改器 / 换向交换器被旋转器转过去时，朝向字符串保持原样。
  ❓ 这一条我按你这次说的「只有交换器」做了；如果你希望**活塞 / 修改器也一起转朝向**（更贴近"物理旋转"的直觉），
  说一声，改 `js/rules.js` 里那个判断就行（一行）。
- 交换器的位移动画（圆弧）和换向动画现在是**同一段 0.30s**，方向也一致。

## 7. 附带修掉一个我自己造成的问题（重要）

**问题**：`tests/run-probe.ps1` 启动无头 Chrome 时**没带 `--user-data-dir`**。
在某些 Chrome 版本 / 启动方式下这会用到真实 profile 的 localStorage，
于是自检建的测试大关（「探针大关」）有可能写进**你自己的关卡库**里。

**证据**：项目根目录的 `关卡库.json` 里（你导出的那份）混着一个 `探针大关 / 7-1`，
而你的真实关卡是「第一章 8 关 + 第二章 15 关 + 第三章 2 关」。

**做的三件事**：

| 动作 | 说明 |
| --- | --- |
| 1. 堵住源头 | `run-probe.ps1` 现在**强制使用一次性临时 profile**（和 `check-single.ps1` 一样），跑完就删；以后自检再也碰不到你的关卡库 |
| 2. 清干净文件 | 新增 `tools/clean-library-file.js`：只删指定名字的大关（默认就是自检留下的那几个），**先备份成 `关卡库.bak.json`**。已对你的 `关卡库.json` 执行：4 大关 / 26 关 → **3 大关 / 25 关** |
| 3. 给了体检工具 | 新增 `tools/cleanup-library.html`：用浏览器打开会**检查浏览器里有没有自检留下的垃圾大关**（不带 `#go` 只体检、不动数据，带 `#go` 才删）。当前默认 profile 检查结果为「干净」 |

用你**清理后的真实关卡**重新打包：`dist\带关卡-我的关卡库.html`（194.6 KB），
真浏览器自检确认选关界面渲染出 **25 张关卡卡片**。

> 如果你的编辑器左边栏里看到了「探针大关」或者重复的大关，点中它 →「删除选中大关」即可
> （自检从来没删过你的东西：所有删除操作都带 `confirm`，无头浏览器里一律返回「取消」）。

## 8. 已知问题 / 取舍

- 「交换器跟着换向」只对 `swap` 生效（见上）。
- 旋转器引起的换向**没有单独的提示音**，用的是旋转器自己的音效。
- `states` 里带了 `byRotator: true` 标记，目前只用于区分来源，没有别的行为。
