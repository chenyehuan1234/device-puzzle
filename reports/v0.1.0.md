# v0.1.0 · 2026-09-19 · 首个版本：框架 + 关卡编辑器（并入「去墙 / UI 重排 / 缩略图 / 音效」这一轮改动）

> 并把最近这一轮（取消墙、界面重排、缩略小地图、音效、快捷键、最小尺寸、右键放下笔刷）的改动写清楚。

## 1. 这次要解决什么

用户提出的 7 条 + 追加 2 条：

1. 墙没用了，删掉（所有地图都是矩形，棋盘外沿就是边界）
2. 编辑器右上角太臃肿：试玩挪到中间、关卡信息挪到左栏；S 一键试玩、B 返回编辑
3. 选关卡片要有缩略小地图
4. 加音效（点击 / 推动 / 通关），WebAudio 合成，不要素材文件
5. 新关卡默认名字用 `1-3` 这种编号
6. 右键空地取消（手中笔刷）；覆盖绘制动画太突兀，要虚化过渡
7. `Ctrl+S` 保存本关并自动新建下一关（尺寸沿用）
8. （追加）尺寸最小限制 3 格是 bug —— 去掉，允许 1×1
9. （追加）右键空地 = **放下手中的设备**（不是擦除）；同时开始 git 版本管理 + 每次写更新报告

**范围**：只做框架和编辑器，不设计关卡（关卡由用户自己画）。

## 4. 规则 / 交互变化

- **墙取消了**：编辑器造不出墙；棋盘外沿（越界）就是边界。
  ❓ 规则引擎里**仍然保留墙这种地形**，只为兼容老存档 / 老 JSON（老关卡还能正常打开和玩）。
  用户若希望「导入时自动把 `t:1` 清成地板」，说一声即可。
- **最小棋盘 1×1**：以前是 3×3。1×1 的关卡当然玩不了（没地方放），但那是用户的事，工具不该拦。
- **右键语义**（按用户最新一句话实现）：
  - 光标下是**干净空地** → 放下手中的笔刷（空手状态左键不画东西，调色板无高亮）
  - 光标下**有东西**（设备 / 图形 / 目标 / 老墙） → 擦干净，可按住连续擦
  - ❓ 这一条和上一轮那句「右键空地方就可以取消目标」我理解得不一样，现在按**这一轮**的说法做；
    如果其实想要「右键空地 = 只取消目标」，改一行就行。
- **Ctrl+S 的空关卡保护** ❓：当前关什么都没有时只保存、不新建下一关（防止手快攒一堆空关卡）。
- 通关判定、9 种设备判定、冲突全有全无 —— **没有改动**。

## 6. 已知问题 / 取舍

- 音效音量偏轻（总增益 0.17），可以调 `js/sfx.js` 里的 `master.gain.value`。
- 缩略图是每次进入选关界面重新画的；关卡特别多（几百关）时可以考虑缓存。
- 老的墙数据不会被自动清理（见上）。
- 编辑器还没有「重做（Ctrl+Y）」，只有撤销。
- 关卡 JSON 里的 `solution` 字段一直留着但没人用（见「下一步」）。

## 7. 下一步建议

1. **解法录制**：试玩时把点击序列记下来存进 `solution`，以后能一键回放、还能给玩家「看提示」
2. **重做 Ctrl+Y**：撤销栈已经有了，加重做栈很便宜
3. **框选 / 矩形填充 / 区域复制粘贴**：画大关不用一格一格点
4. **键盘光标**：WASD 移动画布光标、回车落笔，画大关比鼠标快很多
5. **整章导出 / 导入**：一次带走一个大关的所有关卡
6. **每关最少步数记录**，选关卡片上显示「最少 N 步 / 你的 M 步」
7. **关卡体检增强**：检查有没有图形被彻底堵死（不可解）
8. **关卡内提示文本**：`note` 字段已经有了，试着在关卡里显示出来
