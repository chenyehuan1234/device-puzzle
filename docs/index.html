快捷键
S 试玩本关
B 试玩中返回编辑
Ctrl+S 保存并新建下一关（同尺寸）
Ctrl+Z 撤销　R 转笔刷（Shift 反向）
滚轮 设备换朝向；正方形/圆形/方形目标/圆形目标之间循环
中键 吸取　右键 有东西=擦掉这一格（含目标）　空地=放下笔刷
Esc 放下笔刷　1空地 2正方形 3圆形 4方形目标 5圆形目标 0取消目标
